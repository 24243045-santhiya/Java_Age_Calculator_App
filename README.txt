JAVA AGE CALCULATOR - DESKTOP GUI APP

Requirements:
- Java JDK installed
- Windows, macOS, or Linux

Run in PowerShell:
1. Extract the ZIP.
2. Open the extracted folder in VS Code or PowerShell.
3. Run:
   javac AgeCalculatorApp.java
4. Run:
   java AgeCalculatorApp

The app opens as a desktop window. Enter your birth year and click Calculate Age.
It calculates approximate age as current year minus birth year. Exact age needs your birth month and day too.
